# Other MCP clients

The same server works in Cursor and CLI inspectors.

### Cursor / manual config

Project files:

- `.cursor/mcp.json`
- `.vscode/mcp.json` (reference)

Build first:

```bash
npm run buildmcp
```

### MCP Inspector

```bash
npm run test:mcp
```

Open http://localhost:6274 and invoke tools directly.
