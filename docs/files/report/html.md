# HTML reports

Self-contained HTML pages with inline CSS, dark/light theme support, and visual pass/fail indicators. No external dependencies — the file can be emailed, attached to a ticket, or served from any static host.

**Default filename:** `test-results.html`

## Functional reports

Overview cards and test sections. Suite-only rows use the same layers-style suite icon as the Multimeter suite UI and are not expandable.

## Load reports

Overview cards, load metrics, SVG time-series charts, snapshots, thresholds, and errors when available.

See [Reference — Load report](./reference.md#load-report-kind-load) for the source schema.
