# Reference (types)

- type: `loadtest`
- title: string
- description: string (supports Markdown)
- tags: string[]
- test: string (path to a `type: test` `.mmt` file)
- threads: number
- repeat: string | number
- rampup: string
- export: string[] (paths to report files)
- environment: object
  - preset: string
  - file: string
  - variables: object
