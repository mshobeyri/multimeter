# Generating docs from the CLI

Use `testlight doc` to render a `type: doc` file to HTML or Markdown:

```sh
testlight doc path/to/catalog.mmt
```

Custom output path:

```sh
testlight doc path/to/catalog.mmt --out ./public/catalog.html
```

Generate Markdown instead of HTML:

```sh
testlight doc path/to/catalog.mmt --md --out ./public/catalog.md
```
