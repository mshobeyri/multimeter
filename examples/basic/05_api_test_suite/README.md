# API example `expect` in a suite

This example shows a `type: api` file with per-example `expect`, listed in a suite.

```bash
npx testlight run suite.mmt
```

Select the `ok` example in the Tests tab (or Send with that example) to evaluate the checks. See [API reference](../../../docs/files/api/reference.md) and [call expect](../../../docs/files/test/steps/call.md#expect).
