# Library Bruno collection

A small Bruno collection (`bruno.json` plus one `.bru` file per request). Open any request with **Open as MMT**.

- **As API** — the selector lists every request in the folder. Pick one and Send.
- **As Test** — runs the whole collection in `meta.seq` order.

The left editor stays on the file you opened. Switching the selector only changes the tester on the right.

All requests hit [test.mmt.dev](https://test.mmt.dev).
