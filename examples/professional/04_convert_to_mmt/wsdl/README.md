# Multimeter Test Server — WSDL

Multi-operation WSDL convert sample. The sandbox is HTTP-first; operations use `https://test.mmt.dev/xml` as the SOAP address so **Convert to MMT...** still produces several `type: api` files.

- Source: `source.wsdl`
- Converted APIs: `converted/api/`

See the [professional convert overview](../README.md). For a one-operation sample, see [intermediate WSDL convert](../../../intermediate/25_convert_to_mmt/wsdl/).
