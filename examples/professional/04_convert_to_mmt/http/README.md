# Multimeter Test Server — HTTP

`source.http` lists the public [test.mmt.dev](https://test.mmt.dev) HTTP endpoints (samples, echo, status, auth, inspect).

**Open as MMT** shows each named request in the selector. **Convert to MMT...** produces `converted/api/` plus a flow test under `converted/tests/`.

See the [professional convert overview](../README.md). For a one-request sample, see [intermediate HTTP convert](../../../intermediate/25_convert_to_mmt/http/).
