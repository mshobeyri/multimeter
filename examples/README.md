# Multimeter Examples

The examples are grouped by complexity so new users can start simple and add power only when they need it.

## Basic

- `basic/01_simple_api` - run one simple GET API and simple POST APIs.
- `basic/02_simple_test` - write a direct HTTP test without inputs, outputs, imports, or API abstraction.
- `basic/03_environment_variables` - use a plain environment variable without presets.
- `basic/04_basic_suite` - run a small suite of simple HTTP tests.
- `basic/05_basic_documentation` - render simple input/output parameter documentation.

## Intermediate

Use these when you are ready for reusable APIs, authentication, mock servers, richer environment variables, inputs and outputs, suites, imports, data-driven tests, environment presets, documentation options/ranges, control flow, helper JavaScript, and additional protocol or file formats.

## Professional

Use these for higher-complexity workflows such as reports, TLS/mTLS certificates, load testing, external mTLS smoke tests, and converting external API collections into `.mmt` files.
